##  О проекте

Проект представляет собой учебное REST API приложение, демонстрирующее навыки разработки на **ASP.NET Core**. Сервер позволяет управлять коллекцией видеоигр: добавлять, просматривать, обновлять и удалять записи. Данные хранятся в памяти сервера (in-memory storage).

###  Цели проекта

- Закрепление навыков создания веб-серверов на ASP.NET Core
- Практическое применение HTTP-методов (GET, POST, PUT, DELETE)
- Работа с маршрутизацией и контроллерами
- Возврат корректных HTTP-статус-кодов (200, 201, 204, 400, 404)
- Тестирование API с помощью инструмента curl

##  Запуск проекта

### Требования

- [.NET SDK 8.0+](https://dotnet.microsoft.com/download)
- Git (опционально)
- curl (встроен в Windows 10/11, macOS, Linux)

### Инструкция

```bash
# Переход в папку с проектом
cd GamesApi

# Запуск сервера
dotnet run
```

Сервер запустится по адресу: `http://localhost:5xxx` (порт будет указан в терминале).

##  API Endpoints

| Метод | Маршрут | Описание | Успешный статус | Ошибки |
|-------|---------|----------|-----------------|--------|
| GET | `/api/games` | Получить все игры | 200 | — |
| GET | `/api/games/{id}` | Получить игру по ID | 200 | 404 |
| GET | `/api/games/favourites` | Получить избранные игры | 200 | — |
| POST | `/api/games` | Добавить новую игру | 201 | 400 |
| PUT | `/api/games/{id}` | Обновить игру | 200 | 400, 404 |
| DELETE | `/api/games/{id}` | Удалить игру | 204 | 404 |
